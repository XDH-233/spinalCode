算法说明（与 RTL 行为对应）

级 0 半加：把相邻两个 bit 合成 2bit 计数。cnt(0) := a ^ b，cnt(1) := a & b，即 {a&b, a^b}。奇数个输入时最后一个 bit 直接转成 2bit 数。

逐级合并：nodes.grouped(2).map { case Seq(a,b) => a +^ b; case Seq(a) => a.resize(a.getWidth+1) }。每级节点数减半、位宽加一；落单节点透传但仍加宽，保证整层位宽一致。

末尾 resize：树内部末级位宽为 D+1，输出位宽为 log2Up(N+1)。非 2 的幂时内部多 1 位，末尾 resize 截断；最大计数 N 一定能装进输出位宽。

纯组合：RTL 没有 clk / rst。这里的“级”是组合传播模型，不是时钟周期；分步只是为了让数据依赖可见。

级 0:  cnt(0) := a ^ b
        cnt(1) := a & b

合并:   nodes = nodes.grouped(2).map {
          case Seq(a, b) => a +^ b          // 位宽 +1
          case Seq(a)    => a.resize(a.getWidth + 1)
        }

输出:   io.count := nodes.head.resize(io.count.getWidth bits)
