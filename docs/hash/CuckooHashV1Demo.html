说明

本页是 v1 的行为模型：CRC-8（poly 0x9B / 0x1D，init 0xFF）给出两个候选桶；APPEND 优先写 h0，再写 h1；两个桶都满时进入逐出慢路径，随机踢出 victim，按 src 标签改投；alt == cur 或 kickCnt == 8 时把 pending 写入 stash。进入慢路径前会预检 stash，满则返回 UNAVAILABLE 且不写表。

为便于观察，桶表缩小为 16 桶（取 CRC-8 低 4 位），RTL 默认是 256 桶；桶深 4、stash 4、maxKicks 8、src 标签和失败原子性与 RTL 一致。绿色=写/命中，红色=victim，黄色=当前读桶。右侧 APPEND 统计对应 RTL 的 stat 输出：kickHist[0]=快路径，kickHist[k]=慢路径踢出 k 次。
