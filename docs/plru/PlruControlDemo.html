算法说明(与 RTL 行为对应)

树状 PLRU:N 路对应 N−1 个树位 state。命中:沿"根→叶子"路径把每个位指向不含该路的子树(该路变最近使用)。缺失:从根沿位走到叶子,即 plru_entry 驱逐路;填充后以驱逐路 id 更新树。

替换阻塞 with_rpl_blk:缺失启动替换时阻塞该路(plru.io.context.valids),驱逐寻路永不到达阻塞路;rpl_end 释放。no_more = ~valids.orR 时,缺失的 update.ready=0 → 背压(valid 保持)。

老化看门狗 with_aging:每路一个计数器,每时钟沿 +1(仅已填充路),访问(命中该路或缺失填充该路)时清零;达到 aging_cycles 且老化有效位仍置位 → 断言 WARNING: A cache line died。仅告警不动作,由外部处理;有效位只在填充时置位、死亡时清除 —— 死亡后即使再次命中也不会重新置位(忠实模拟 RTL 的 setWhen/clearWhen 优先级)。

冲突断言:同一周期 rpl_start 与 rpl_end 指向同一路 → WARNING: Replace the replacing cache line;由于 setWhen 后写优先,该路被释放。
